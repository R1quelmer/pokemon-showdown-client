# Avatares locais da Copa Rinha

Adicione aqui arquivos PNG, GIF ou WebP autorizados dos participantes.
Nenhuma imagem ou identidade foi inventada/adicionada nesta etapa.

Configure `../avatars.json` com IDs de imagens e associações administrativas.
Consulte `COPA-RINHA-IDENTITY.md` na raiz do repositório para formato e limites.
O avatar só é usado depois que o arquivo carrega corretamente; caso contrário,
o renderer mantém o avatar nativo recebido pelo protocolo.

A associação é visual e pública. Ela não verifica quem está usando um nickname.
